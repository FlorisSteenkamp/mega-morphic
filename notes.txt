Send new patch version to npm
-----------------------------
From cli
1. update package versions (`ncu` or `ncu -u`or `ncu -u --reject typescript`)
2. `npm install`
3. `npm run dev
4. `npm test (skip if coverage below will be run anyway)
5. Commit changes locally and push
